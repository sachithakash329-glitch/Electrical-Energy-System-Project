# Capture screenshots from your own running application

These files are not supplied as completed evidence. Add the actual screenshots after testing on your computer. Keep images clear and remove unrelated tabs, account details and credentials.

| Suggested filename | What it should show |
|---|---|
| `dashboard.png` | Desktop dashboard, populated inventory and summary |
| `details.png` | Appliance detail section with usage inputs |
| `edit.png` | Edit form and a changed saved value |
| `delete-confirmation.png` | Confirmation identifying the selected appliance |
| `validation.png` | A rejected input or a clear validation message |
| `mobile.png` | Dashboard/form at about 390 px viewport width |
| `database.png` | Stored appliance/room/settings documents, without secrets |

Add the screenshots to the main README with relative links, for example:

```markdown
![Dashboard and saved appliances](docs/screenshots/dashboard.png)
![Mobile layout](docs/screenshots/mobile.png)
```

Only add links after the files exist. Choose a few readable screenshots for the report instead of squeezing every screen into one tiny image. The report still has a maximum of ten pages.
